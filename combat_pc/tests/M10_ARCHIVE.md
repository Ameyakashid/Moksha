# M10 verification downloads

The project includes runnable regression scripts and readable acceptance reports. The generated JSON report collection and detailed evidence are delivered separately:

- `MOKSHA-PC-Held-Verification.zip`: final held-input, visual/native/portable proof and the generated JSON report collection
- `MOKSHA-PC-Held-Corrections.zip`: retained defect reproductions and their distinct before/after provenance
- `MOKSHA-PC-Held-Traversal-Compatibility.zip` and `MOKSHA-PC-Held-Combat-Compatibility.zip`: all nine earlier suites against the M10 controller

Each archive contains a `MOKSHA/` folder. Extract it beside the source project's `MOKSHA/` folder so the folders merge; do not create another nested project folder. No evidence archive is needed to play.

The detailed reports pin the exact controller, resources and evidence hashes. Historical raw datasets remain in their earlier companion archives; see [the historical index](TRACE_ARCHIVE.md) and the project-level DELIVERY_CONTENTS.md. The latest JSON report collection includes the earlier accepted reports, whose hashes still identify their own original checkpoints.
