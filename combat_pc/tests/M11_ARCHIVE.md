# M11 verification downloads

The source project includes runnable regression scripts and readable acceptance reports. Detailed generated evidence is separate:

- `MOKSHA-PC-Entry-Verification.zip`: final entry-facing cases, component reuse, native comparison, portable proof and generated report collection
- `MOKSHA-PC-Entry-Corrections.zip`: retained development and recorder-correction provenance
- `MOKSHA-PC-Entry-Traversal-Compatibility.zip`: seven earlier movement/traversal suites against the M11 controller
- `MOKSHA-PC-Entry-Combat-Compatibility.zip`: shield and chain suites against the M11 controller
- `MOKSHA-PC-Entry-Held-Compatibility.zip`: held-input suite against the M11 controller

Each archive contains a `MOKSHA/` folder. Extract it beside the source project's `MOKSHA/` folder so the folders merge; do not create another nested project folder. No evidence archive is needed to play.

Reports pin controller, contract and evidence hashes. Previous raw datasets remain in their original archives, linked by [M10](M10_ARCHIVE.md) and [the historical index](TRACE_ARCHIVE.md). Current compatibility runs have separate names. A later report does not replace or reinterpret a historical acceptance record.
