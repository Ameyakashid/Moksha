# Current playable state

> This inventory describes the accepted baseline. The current experimental branch also contains the [Market/irritant preview](EXPERIMENTAL_MARKET_IRRITANT_PREVIEW.md), which has not passed its native visual review. Do not read baseline acceptance as acceptance of every preview change.

This inventory describes this source checkpoint, built on accepted `7be2c80`
with the separately verified ladder-clarity follow-up. It is a
**five-level, 32-district prototype**, not the entire original
MOKSHA vision. Historical milestone documents retain their original evidence.
An unpushed source checkpoint does not change a GitHub clone or an older export.

## What is playable

| Area | Current scope |
|---|---|
| Campaign | City plus four tower floors; authored traversal, machinery, rescue/record routes, captain seals and Warden/final local-custody/public-record choice. |
| Builds | Neutral/Strength/Agility starting lenses, four level-exit upgrades and optional field augments. |
| Sight | Optional sacrifice removes ordinary world paint and improves movement/sound traces. Genuine nearby sound geometry, not a painted replacement map. |
| Hearing | Optional first-level-exit exchange, after the ordinary upgrade. Removes player pulses, sound-map and informative world/body audio. Visible unobstructed melee commitments can gain a bounded late-strike opportunity marked by white brackets. Not automatic parry, global slow motion or a damage bonus. |
| Other perception | Capped coarse scent for life/blood/supplies; body-local ladder contact presentation; quiet contextual Intellect text. These are not complete substitute senses. |
| World presentation | Original environment treatments for all five levels, layered neon opening and background crowds. Newer Market source adds textured stalls, a rooftop refuge and decorative residents behind the playfield. |
| Continuity | District checkpoints, preserved legacy bytes, stable run identity, immutable completed results and read-only result review. |

Normal menus currently withhold a second irreversible sight/hearing loss. The
save/domain can represent both lost without secretly restoring sonar, but full
blind-and-deaf traversal is not validated. The temporary restriction is explained
in the offer, not asserted as permanent game canon.

## Ladder-clarity follow-up

The contextual footer now teaches both climbing directions, holding Up until
standing on the ledge, sideways release and jumping off. Near the known ladder
top, the operator stays in a compact pull-up silhouette before rising into the
supported ready pose. This is presentation only: no root/boot displacement,
collision assistance, automatic input or new traversal rule.

The first pose experiment was rejected after native review despite passing its
mechanics checks. The second, `7fb59a8`, was reviewed at actual size and in genuine
retained-sight and blind Market checkpoint routes. Their 1,588/1,615 recorded
gameplay samples exactly match the accepted baseline; key collection, descent,
75 HP and ordinary closure are unchanged. The original failed experiment remains
historical evidence, not part of the selected runtime. Twenty-five interruption
checks are seeded visual-event assertions, not new native combat testing.

The compact pose reads more distinctly in those captures, but fresh human
usability remains untested. A suspected missing-letter artifact during full-frame
inspection was rechecked: the source header pixels exactly matched the older
baseline and enlarged inspection showed complete text. No font fix was made.
This source follow-up does not change the previously delivered Windows runtime.

## Evidence means different things

The combined hearing/camera runtime completed all 32 districts with hearing
traded in a recovered multi-process ordinary-input automated run, zero deaths,
stable prior receipts and same/fresh-process completed-result review. It was not
one continuous full-campaign movie or a human playthrough.

The newer Market video is continuous native Linux capture, known-route automated
inputs, all four mandatory objectives and ordinary next-district/Title return.
Its original audio stream was checked, not subjectively mix-reviewed. Separate
fresh screenshot-only AI play reported apparent ladder-top ambiguity; one Market session was
interrupted and safety-closed. That partial run is not a completed acceptance
test, but its observations are retained rather than discarded.

Native Windows, physical-controller behavior, target real-time frame rate,
subjective audio mix and general human usability remain unverified. MovieWriter
uses a fixed simulation timeline; its video duration is not wall-clock speed.

## Save safety

New checkpoints use **envelope v3** and explicit sight/hearing facts. New completed
records use **schema 2**. Valid older v1/v2 checkpoints and historical completion
records remain supported, with original bytes preserved before migration.
Before switching builds, close the game and back up the entire save folder.
Use one running writer. Restore a matching old backup for an old build; never
hand-edit the version or point an older build at a new v3 checkpoint.
