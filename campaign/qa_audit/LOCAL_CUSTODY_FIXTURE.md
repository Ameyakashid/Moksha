# Alternate ending fixture

`local_custody_fixture.gd.txt` preserves the exact externally executed GDScript as text evidence without changing the frozen Godot source manifest. Copy it to a temporary `.gd` path to rerun with Godot's `--script` option and `-- --hz=60` or120, using isolated HOME/XDG directories.

This uses controlled final-district setup, then an ordinary K event. It is not a second full-campaign traversal. It verifies the local-custody ending, persisted result, Continue replay and New-run outcome retention. Logs and source hash are recorded in `local_custody_review.json`.
