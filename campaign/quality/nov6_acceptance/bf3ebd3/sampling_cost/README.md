# Bounded controller-sampling measurement

The exact b2 and bf3 snapshots were compared in six balanced baseline/candidate pairs. Raw reads add roughly 38–39 microseconds and playing HUD snapshots roughly 37–41 microseconds in this environment, about 9x the tiny raw baseline but about 0.08 ms for one extra raw read plus one HUD snapshot. Explicit overrides remain near baseline. Measured blocks retain no additional objects/resources; a separate 600,000-call recorder reports flat native static-memory usage. This is not a zero-temporary-allocation or hardware-FPS claim. No runtime optimization was made.

The archive contains all original observations and a separate portable wrapper with new-output refusal, strict receipt parsing, exact commit archives and source checks. Its setup smoke and 16 negative/parser tests are labeled separately from the original six-pair measurements. Extract into a fresh directory and follow its README. Full source archives and private HOME/XDG/cache trees are excluded; the complete Git-history companion supplies the required commits.

Shared cloud CPU, headless frozen first-district scene, real raw/HUD methods but no moving-actor or renderer benchmark. Relative slowdown, variability and limitations remain explicit in REPORT.md.
